# Buick VCS 大联屏兼容画像（阶段一 / Buick-Test）

**目标**：逐步支持使用别克大联屏的多款车型，但车型销售名称、屏幕外观和可修改的蓝牙名称，都**不能**直接证明 CarPlay 协议相同。

## 当前已实现的安全边界

1. 「连接准备 → 选择设备」原本就把用户显式选择的已配对车机**按蓝牙地址**保存在本机，改蓝牙名称不会使选择失效。用户选定目标时，即使 SDP 不公布配件端 UUID，出站仍会尝试该目标；其它已配对设备不会被误连。
2. 旧 `BUICK_[0-9]{4}` 规则仍是初次发现时的**辅助提示**，不是车机身份认证，也不再是再次识别已成功连接 B233 的唯一依据。
3. **仅当**车机的 iAP2 0x1D01 身份匹配原有 B233/SAIC General Motors 条件、按 B233 流程收到了有效 0x4301 并形成端点后，才在本机保存“观察到 B233 协议”的记录。记录使用标准化蓝牙地址的 SHA-256 派生键；不上传地址或匹配键，应用禁止备份。
4. 下次连接时，原始名称即使改变、隐藏或不匹配旧规则，已观察到的同一蓝牙设备仍可进入 B233 专属 SDP 兜底、保留 HFP/A2DP、重连冷却以及受限的反向连接流程。
5. **未观察到的车机不因“别克”标签、屏幕规格或用户选择而直接进入 B233 特殊握手。** iAP2 身份分流仍独立校验；非 B233 接收端维持已有默认处理，以免影响奥迪/测试台。

## 目前尚未覆盖

- 车机首次配对前就改名且 SDP 不公布配件 UUID：必须先在连接准备中**手动选择目标**，才能绕过自动发现过滤。其首次连接仍须按实际 iAP2 身份确立兼容配置。
- 若首次尝试时车机要求特定蓝牙 profile 保留时序，新车型还可能需要经过真车验证的显式兼容档位；目前不猜测其它别克型号属于 B233。
- 连接后重新配对并发生蓝牙设备地址变化、App 清数据/卸载后重新安装：需要再次学习。当前只保存 B233 已成功握手画像，不创建未经验证的 E4、昂科威、君越或 GL8 兼容声明。
- 此阶段不修改 AirPlay 音频、视频、触摸、T31 marker 探针或 Gateway/MCP。音频断连和 Xperia 系统重启问题单独处理。

## 回归验证

- 旧名称 `BUICK_1234` 未有学习记录：兼容原先发现路径。
- 已学习 B233 地址配任意改名/无名称：仍走 B233 蓝牙传输辅助策略。
- 未学习的普通设备、耳机、奥迪、DiPlay：不自动进入 B233 策略。
- B233 身份匹配但未完成 0x4301：不写入学习记录。
- 实车测试建议：原名成功一次 → 仅改车机蓝牙广播名称 → 保持配对后重连；并与未学习设备分别对照，关注 RFCOMM、0x1D01、0x4301、音频及视频/触摸。
