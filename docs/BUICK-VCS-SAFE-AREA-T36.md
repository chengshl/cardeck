# Buick-Test T36 — 仪表盘地图与设置页右侧留白

## 复现证据

2026-10-23 E5 T35 现场照片显示：
- 第一屏仪表盘的地图卡片顶部仍贴近弧面屏边缘；
- 「车机设置 → 管理桌面应用」交互项已进入安全范围，但右侧原本的区域呈黑色带，与整幅紫色壁纸不连续。

根因：
1. T34/35 仅给 `GridActivity` 内 ViewPager 加顶部 safe-area margin，但仪表盘地图是 `DualDisplayComposer` 直接绘制的**另一块地图虚拟屏纹理**；SPLIT 代码依旧写死上下边距为 `CARD_MARGIN_PX=16`。
2. T35 通过对 `activity_settings` 黑色不透明根布局增加 `paddingRight` 避让 286px，控件进入安全范围，但原背景仍填充黑色，所以边缘形成大面积黑带。

## T36 改动

- 横屏 dashboard SPLIT 地图：新的 top inset = reported viewport.top + CARD_MARGIN_PX（E5 44+16=60），bottom = reported lower safe inset + CARD_MARGIN_PX（E5 0+16=16）；地图 tile 高度与 map virtual display/GL draw rect 同步变为 520-60-16=444px，保持画面比例，不改 RTSP 视频尺寸与其他应用。
- 地图触摸：限定命中在真实可视 tile 的横纵坐标内，对应扣除左/上 tile 边距后注入地图显示，不再把顶部空白识别为地图事件。
- 未开别克设置总开关、该车选择 off、无 safeArea、竖屏时保留既有 16px 上下地图边距。
- 车机设置页：保持 T35 内容避让，但使用根布局 margin 让出右/上/下区域，后方放置与 Dock/Grid 相同的全流画布 aspectFill 壁纸切片。不再用黑色背景填充未利用的曲面安全带。触摸及原有虚拟屏大小不变。
- 更新仅进入 Buick-Test，不动音频、iAP2 握手、T31/T32、其它分支。
- E5 非全屏仪表盘地图属于本次范围；地图全屏模式及其他第三方 App 贴边控件仍需独立验证。

## 实车核对

1. 连接 T36、E5 模式自动，仪表盘地图顶部应比 T35 向内约 44px，地图/音乐卡上缘接近对齐，卡片内图标/导航比例不变。
2. 在地图卡顶部新增留白处触摸不应误打开地图，地图实际可视内容仍能精准触摸。
3. 打开「车机设置 → 管理桌面应用」，右侧空白应与整幅壁纸连续，而不是黑色条带；右侧勾选框仍在可视安全区。
4. 关闭别克安全区总开关重新连接，应恢复旧版布局，方便对照。
