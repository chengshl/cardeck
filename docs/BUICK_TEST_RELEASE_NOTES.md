本次更新：别克 E5 测试版 T73 · 补齐音频 SETUP 中缺失的手机反向 RTCP 控制端口。

已确认 T71 实车可正常播放 AAC-LC 48kHz 音乐，采集非零并向车机发送约 949 包，但约 20 秒后整条 AirPlay/iAP2 会话断开。T71 不向车机 6011 发送传统 0xD4，同步端口拒绝已不是这轮断开的必要条件。

本次修改：
- 对别克 B233 的 type=102/media AAC-LC 流，按 CatPlay 音频发送端的真实流程，在 SETUP 之前创建并绑定到车机 WiFi 的**手机本地反向 RTCP UDP 端口**，并在 SETUP 请求里新增 controlPort 字段。
- 区分“手机的本地控制端口”和“车机在 SETUP 响应里返回的远端 controlPort（先前为 6011）”；二者不是同一个端口。新监听只被动接收车机控制数据并记录包数量、长度与类型，不主动发送任何新同步报文。
- 音频停止、协商失败或 CarPlay 会话结束时关闭本地监听，避免留下旧端口。
- 新增本地 UDP 端口启停及网络绑定失败路径的单元测试，失败时不启动缺失所需端口的实验音频，以免影响仅视频模式。
- 保留 T71 已能实车出声的 AAC-LC、48kHz、RTP、RECORD、高精度时间戳及不主动发送传统 0xD4 的策略；普通蓝牙 A2DP、主动连接、视频与其他车型均不变。

注意：T73 仅修复已核实的协议请求缺口，目前并未在别克 E5 上证明可长时间稳定。需要实车确认车机出声、反向控制包情况与运行超过 3–5 分钟；不要把 SETUP 200 或 RTP 包数当成成功验收。
