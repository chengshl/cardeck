本次更新：Buick-Test 在线更新双通道与安装包构建时间（更新基础设施，不调整 CarPlay 音频协议）。

- 「别克设置 → 在线更新」现在可选择正式测试版或实验版本。正式测试版继续使用独立的 buick-test-latest 通道，默认自动检查只针对正式测试版。
- 实验版本只在用户主动打开列表时查询，必须属于 Buick-Test，来自 GitHub 独立预发布并包含校验 APK / SHA-256 / 真实构建时间，下载安装前验证来源、包名及版本。实验包还必须携带 updaterSchema=1，避免安装旧实验包后失去实验版本选择入口。不会因为有新实验自动安装或覆盖更新通道。
- 两个渠道展示构建完成时间（北京时间）；旧 Release 未写明真实构建时间时，仅显示版本标识时间，避免用提交/发布时间冒充构建完成时间。
- 实验 APK 沿用现有 Buick-Test 的包名与签名；低于已安装版本号不能覆盖回退，界面会明确提醒。新实验列表出现的前提是独立预发布已经签发，GitHub Actions Artifact 本身不等于已发布的在线安装包。
- 保持视频、触控、车机网络、蓝牙 A2DP 与 T73 AAC 参数原状；Buick-main / Buick-E5 也独立加入同样更新入口，不跨分支下载。
- 代码编译与单元测试需要 GitHub Actions 最终结果确认；此更新不表示 T73/T75 的音频20秒断开已修复，也不代表真车下载安装和回退已验收。

对应记录：GitHub Issue #17（全开发/测试分支实验版本手动选取），音频实验仍见 Issue #11。
更新发布补充：正式 Buick-Test 的 GitHub Release 已增加 builtAt=UTC 时间戳，页面转为北京时间显示。实验包在隔离预发布上架并实车验收前，仍不代表可安全长时间使用。
