本次更新：别克 E5 测试版 T70 · 修复音频晚授权启动流程。

- 修复已连接 CarPlay 后再授予音频采集权限时，仅启动 RTP、未补发 RECORD 的确定性缺陷。
- 首次建链与会话中补授权共用音频 SETUP → RECORD → 同步闸门放行的完整流程，避免晚授权音频一直等待 RECORD。

- 保留已验证的主动连接与仅视频逻辑，未修改 AAC/PCM 优先级、RTCP 6011 行为、音频撤销协议。

注意：本版只修复“晚授权”路径。先前实车已完成 RECORD 后仍出现的 RTCP 6011 ECONNREFUSED、采集全零和整链断连问题尚未解决，不能宣称车机音频已稳定。实验性音频默认关闭。
