# Buick E5 T63 · 车机屏任务残留与重复最近任务（2026-10-26）

## 现场反馈及原因
用户反映，每次使用 CarDeck 后手机最近任务/后台会出现多个重复的 App。当前 E5 使用双应用屏（原生/Hi）和地图屏，初次路由某应用至独立车机屏时，在必要情况下仍使用 `NEW_TASK | MULTIPLE_TASK`。其目的是在系统存在手机屏任务时创建车机独立任务，但已有的车机任务应在虚拟屏销毁时结束。

**根因修正：** 此前 trusted shell UserService 建屏和 app public fallback 建屏，均未指定 `VIRTUAL_DISPLAY_FLAG_DESTROY_CONTENT_ON_REMOVAL`（AOSP `1 << 8`，隐藏系统常量）。Android 对**公开虚拟屏**的定义：没有该 flag 时，屏幕移除会将屏幕上的活动迁回主屏栈；加上则销毁该屏内容。源码：`frameworks/base/core/java/android/hardware/display/DisplayManager.java`。

## 安全边界
**绝不清除历史手机侧最近任务**（无法可靠区分旧的车机迁移任务和用户正常手机任务），也不使用 `am force-stop`、`pm clear` 或通用 `am stack remove` 扫描手机屏。旧有残留可由用户在手机最近任务界面手动划掉；新代码只控制**本次以后车机虚拟屏被释放时的生命周期**。
