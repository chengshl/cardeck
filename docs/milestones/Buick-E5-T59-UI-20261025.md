# Buick E5 T59 — daylight dashboard polish (2026-10-25)

T59 improves the **UI-only** main dashboard using the real-car comparison supplied by the owner.
Baseline: E5 T58 commit `a88dbe06f9ba4f2e1da533d9bfd92acbc8001587`.

## Implemented
- Daylight/ivory translucent cards with soft borders and dark legible text.
- Compact navigation header, action "打开" opens selected default map **without pretending that a route was started**.
- Balanced music card with real MediaSessionsState album art, song/artist, progress and live media-key controls.
- Dashboard card transparency property `DockPrefs.cardOpacity` (45–100, default 92) with same live listener as existing scrim/blur. **Manual UI control deferred** as requested.
- Existing DockPrefs dark scrim / wallpaper blur sliders already live-update Dock and dashboard wallpaper. This is not a claim of true cross-window GPU backdrop blur.
- Keeps user-selected full-canvas wallpaper and existing GL map-tile / virtual-display geometry, touch mapping, audio and CarPlay transport.
