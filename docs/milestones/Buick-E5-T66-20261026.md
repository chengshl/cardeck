## 验收与注意
1. 先从手机最近任务中手动整理 T65 以前历史残留卡片；不要清除 App 数据。
2. 手机上可以保留一个自己主动打开的 QQ 音乐、高德任务；连接车机并各打开 QQ 音乐、高德，再重复打开 3～5 次，检查手机原任务不被隐藏或停止。
3. 断开并重复三轮连接，检查手机 Recents 是否不再新增车机卡片；核对 `LIFECYCLE T65 release=true` 与 remaining=0。
4. 验证 Dashboard 地图卡首帧显示、地图导航状态、QQ 音乐任务复用和 T64 转场。
5. 若 Android OEM 启动器仍展示排除的任务，需要收集**脱敏**任务 rootIntent 标志与所属 display ID，才考虑后续精准任务移除。不要按包名全局 force-stop、删除用户手机任务或绕过系统权限。

此 flag 改变任务在手机 Recents 的可见性，**不代表杀进程或删除历史卡片**。音视频、CarPlay iAP2、触摸映射、显示几何、T57 原始保护里程碑不变。问题归属 #15，关联 #14/#16/#12。
