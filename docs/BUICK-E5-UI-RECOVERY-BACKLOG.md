# Buick E5 · CarPlay 原生界面切换恢复待办

> 记录日期：2026-10-24（北京时间）。状态：**Backlog / 暂缓**。当前仅记录问题，不做代码或行为变更。
> 范围：CarDeck 在别克 E5 上的投屏界面与原生车机 UI 切换。此文档放在 Buick-Test 分支作为后续优化依据；两个问题均可能涉及车机 UI/焦点/状态管理，不假定只属于某一 APK 分支。

## P1. 原生空调弹窗后 CarPlay 画面透明/不可见

### 用户实车复现
1. 正常打开 CarPlay 投射页面。
2. 打开车机原生空调控制弹窗。
3. 返回 CarPlay 时，CarPlay 整块内容不可见，表现类似整个 CarPlay 模块透明化。
4. 只有先切到车机**其他不含弹窗卡片的页面**，再切回 CarPlay，显示才恢复。

### 对照与预期
- **原版 iPhone CarPlay 没有这个问题**。
- 空调弹窗关闭或切走后应直接恢复原 CarPlay 画面，不需要通过其他车机页面中转。

### 假设（均未验证）
- 原生空调界面的遮罩/Window/Surface 图层在切换后未清除或恢复；窗口透明度、Z-order 或可见性异常。
- 视频流可能仍在传输，但接收端 UI 图层不显示；也可能是 CarDeck 未及时响应前台/模式变化事件。

### 后续取证与验收
- 同路径录制 iPhone 与 CarDeck 复现录像；记录车机 UI 切换顺序。
- 检查消失时编码、视频 TCP、关键帧及 RTSP /feedback 是否仍正常；区分“有流无画面”和“流被暂停”。
- 对照前后台/焦点事件；优先最小恢复方案，不依赖断开重连。
- 验收：弹窗关闭直接返回 CarPlay 画面可见，触摸与音视频功能正常，反复操作不复发。

## P2. 低速变道自动 360° 环视退出后回到车机主页

### 用户实车复现
1. CarPlay 页面处于打开且前台状态。
2. 低速变道触发车机自动显示 360° 环视。
3. 360° 系统界面自动关闭后，车机**返回车机主页**，而不是此前的 CarPlay 页面。

### 对照与预期
- **原版 iPhone CarPlay 没有这个问题**。
- 必须完整保留车机安全摄像头/360° 的优先级；其界面退出后应恢复先前 CarPlay 页面，而非主页。

### 假设（均未验证）
- 车机临时摄像头 Activity / Window 栈退出时没有保留或恢复 CarPlay 前台状态。
- CarDeck 的 CarPlay 会话对某些模式、焦点或 UI 状态事件响应与 iPhone 存在差异。

### 后续取证与验收
- 比较 iPhone 和 CarDeck 在相同触发条件下的页面恢复行为。
- 对照界面切换前后的事件通道、模式声明、视频继续发送、会话是否一直存活。
- 优先修复“原界面焦点/前台恢复”，禁止以阻止或延迟 360° 弹窗作为解决方案。
- 验收：360° 安全影像正常出现和关闭，关闭后自动恢复之前已打开的 CarPlay 页面；不影响安全影像触发、音视频、触控或无线会话。
