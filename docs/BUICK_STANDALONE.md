# Buick E5 独立维护策略

从 T69 开始，CarDeck Buick-Test 按别克 E5（B233）为中心独立演进，不再将持续合并多车型上游 main 作为默认开发路径。

- **独立的开发与发布**：保留现有 Buick-Test 独立包名、签名及更新发布通道；不自动合并上游 main，也不影响 Buick-main 或其他分支。仓库所有权、Fork 关系及历史仍保持原状，需要单独迁移仓库时再评估。
- **选择性移植**：仅在上游新增功能经过车型兼容性审查与定向验证之后，以小范围变更移植。不得因为其他车型修复而改变 B233 的蓝牙、MFi、iAP2、Wi-Fi、音视频握手路径。
- **车型策略隔离**：B233 连接方向由 BuickConnectionModePrefs 决定，默认被动监听；主动连接必须用户明确选择，且重试受时间与会话互斥限制。所有更改下次服务启动生效。
- **稳定优先**：仅视频 + 普通蓝牙 A2DP 为已验证的基础使用模式。CarPlay 音频推送为试验功能，曾实测整条会话被重置及后续 0x4300 不获 ACK，不承诺稳定。
- **后续重构**：逐步把非 B233 的连接策略、测试台兼容层和多车型分支规则隔离出 E5 核心；先保证现有日志、配对与独立更新能正常运作，不做一次性大规模删减。
