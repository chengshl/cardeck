# Buick-Test T39 · 应用显示管理 UI 整理

## 问题
T37 在「别克设置」同一滚动页里嵌入应用选择下拉框、模式下拉框、额外保存按钮，长期应用列表混入包名，操作与视觉都显得像调试界面。

## 本次
- 原「别克设置」仅保留车辆/主页安全区设置，提供一个「应用显示管理」卡片入口。
- 新增单独的手机端 `BuickAppDisplayActivity`：沉稳深色双层卡片设计，车辆标签、默认模式的双卡选择、应用搜索、全部/已自定义筛选。
- 每行显示应用真实图标、应用名称、是否独立配置、当前**实际生效**的「安全区域/全铺满」状态。包名只用来检索/内部匹配，不再占满可见列表。
- 点击某应用弹出圆角选择对话框：「跟随车辆默认」「安全区域」「全铺满」，选择即保存、无需第二次点击保存。
- 车辆默认「安全区域/全铺满」在新页面直接保存，原本 `BuickVehiclePrefs` 的全部键和值不变。已保存的车辆与 App 覆盖方案保持兼容。
- 主设置页保存仅作用于主页安全区，不再意外覆盖在子页设置的 App 默认模式。
- 总开关关闭时允许预先配置，但明确提示：只有开启总开关，安全区 App 模式才会生效。
- 无可识别车辆时不能误入设置。新 Activity 不对外导出，不引入网络、权限、隐私信息存储。

## 不做
- 本次只涉及 UI 和现有偏好调用，不改高德地图的 Android 兼容 letterbox、GL 合成、触摸映射、音频及 iAP2 握手。
- 列表显示的「全铺满」不等于消除 Android 在应用内部生成的 black letterbox。这仍是独立的兼容性问题。

## 实车/手机验收
1. 手机打开「别克设置 → 应用显示管理」，检查深色背景文字和应用图标清晰。
2. 默认模式切换后返回再进入，状态仍被保存；主设置页点击「保存当前车辆方案」不会回滚。
3. 搜索“高德”、点击应用，选择「安全区域」，重新打开高德生效；选择「跟随车辆默认」，覆盖键被清理并随车辆默认变化。
4. 视频应用单独设为「全铺满」与高德相互独立。点击已自定义筛选，只列出存在覆盖方案的 App。
5. 关闭别克安全区域总开关后新页面出现提示，配置可修改但显示逻辑不生效。
