# CarDeck 软件更新 B 方案｜独立实验分支验收

- **基线**：Buick-Test，创建实验分支时HEAD `405c4e6d464178d038158ad390f47d712c8846af`。
- **隔离源码**：`experiment/buick-test-updater-b`；只修改更新页、订阅过滤、测试、独立发布工作流；不改AAC/iAP2音频协议。
- **安装包**：保持 `io.github.buick.test.cardeck`，与手机上 Buick-Test **同包覆盖**，而不是与正式Test并存。
- **发布方式**：实验工作流独立CI/Release `exp-buick-test-updater-b-<年月日时分秒>`，带 `artifactKind=experiment`、`updaterSchema=2`、`sourceBranch`、`baseBranch`、`builtAt`、APK+SHA256；不改`buick-test-latest`。
- **B方案高版本构建**：切换到旧实验时，App不会安装低versionCode、不会卸载App，也不会悄悄换成另一实验。由开发侧**从指定实验源码重新触发签名CI构建**，产生高于手机安装版的APK并在独立新tag发布；随后在App内选择所需实验项目、检查、下载并让Android确认安装。再次构建不能抹除既有Release，不能将其他实验的代码错误混进目标包。
- **回退提醒**：测试实验后若正式版本号较低，需要发布**新versionCode且来源于正式代码**的恢复包，不能靠安装旧APK无损降级。遇不确定先停测并保留日志。
