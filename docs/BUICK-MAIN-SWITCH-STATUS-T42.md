# Buick-main T42 · 别克设置开关状态可视化

## 背景
用户反馈别克设置中“真实桌面与车机触摸”和“CarPlay 曲面屏安全区域”两个 Switch 开关几乎看不出开启/关闭。原界面的 thumb/track 使用 `ColorStateList.valueOf()`，无论 checked/unchecked 都应用相同着色。

## 修改
- 两个开关统一使用独立深色大圆角卡片：左侧功能名和**显式“● 已开启 / ○ 已关闭”**状态文案，右侧真实 Switch。
- 开：青色加粗边框、深青填充、绿色“已开启”，青色开关滑块和轨道；关：灰色边框、深灰填充、灰色“已关闭”、灰色滑块和轨道。
- 整张卡片均可点击切换；Switch 的 checked 值驱动所有文案/颜色，改变后实时刷新，原有的全局首选项写入方式不变。
- 设置状态采用 `contentDescription`，API 30+ 辅以 `stateDescription`，提高无障碍可读性。
- 保留真实桌面/T28 风险说明、安全区提示；改动于下次 CarPlay 连接时生效。
- 不影响 Buick-Test 和 Buick-E5；不修改 iAP2、音频 T41、虚拟屏、HID/画面或分支更新渠道。

## 手工验证
1. 手机打开 Buick-main → 别克设置，确认两处均看到对应当前保存状态的“已开启”或“已关闭”。
2. 点卡片正文、点 Switch 滑块，各切换一次，验证标签、底色、边框、滑块同步。
3. 退出设置重进，状态持久化；另开“应用显示管理”不被两开关影响。
4. 修改后主动断开再连接，验证安全区/真实桌面按开关配置生效。
