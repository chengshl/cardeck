# Buick-Test T34 — 曲面屏安全区不变形布局 + 更新前断链

## T33 实车反馈（2026-10-23）

T33 用全局 `glViewport(left, bottom, safeWidth, safeHeight)` 将横向 1972×520 画面压至 E5 1408×476 安全矩形，图标因此变形，边缘生成深色块（截图确认）。手机「别克设置」页面部分文字在深色主题中不可读；主页新入口缺少图标。首次覆盖安装后无法连接，重启车机后成功，疑似车机残留旧会话但仍未有充分证据确认。

## T34 实现

1. 删除对全画面 GL viewport 的缩放及 TouchRouter 的逆变换。视频尺寸、帧率、wallpaper aspectFill、GL 合成保持 1:1，彻底消除 T33 带来的黑边和图标非等比拉伸。
2. 对横屏车机，在 VirtualLauncher 将左侧安全带作为 dock 虚拟屏壁纸区域，其内的 dockControls 布局按安全区左/上坐标向内放置，剩余背景全屏；应用显示屏覆盖后续完整横向区域。
3. GridActivity 保持壁纸铺满虚拟屏，只有交互性 ViewPager 与 dotsRow 避让右/上/下安全边缘，并基于实际可用 ViewPager 宽高计算应用图标大小；原生 TouchRouter 按实际画布坐标分流。
4. BuickSettingsActivity 为说明、方案、输入框、选车菜单、按钮与总开关指定可读的 Material 3 深色文字与背景；主页入口使用已有车辆图标。
5. BuickUpdater 在 SHA256 APK 核验、安装权限通过且用户确定进入系统安装界面时，先调用 SessionController.disconnect()，退出 CarPlay/BT/WiFi/视频控制会话，减少旧车机会话残留概率。**外部文件管理器、浏览器覆盖安装无法拦截**，必须用户主动断开。无法保证车机一定会即时回收旧会话。
6. 不修改 iAP2 0x4300、MFi、T31、T32、音频或 E5/main 分支。
7. 保留 T33 匿名按车方案，默认关闭，调整设置后下次连接生效。竖屏车型暂不激活 T34 主页安全边缘处理，等待独立验证。

## 实车验收重点

- E5 选择“自动”时，背景无黑边且图标圆形等比例，Dock 与主要主页按钮避开被曲面裁切的位置。
- 左侧安全带是原样墙纸，不是压扁的画面；主页图标不会被裁切；四边手动偏移与触摸命中一致。
- 手机「别克设置」页所有选项/数值有足够对比度，入口出现小汽车图标。
- 在 App 内更新测试：已连接→核验并点击安装→旧会话主动退出→系统安装器出现→新版本连接。与外部 APK 覆盖行为区别记录。
- 若仍出现 0x4300 不 ACK，请按握手日志定位车机状态，不得把更新前退出当作已证明的根因。
- 第三方应用或地图页面本身若有贴边控件，仍可能要求针对 Android WindowInsets/letterbox 做后续专项适配；T34 首先保护 CarDeck 原生 Dock/主页控件。
